# RemoteClaw Feishu/Lark

Official RemoteClaw channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from RemoteClaw:

```bash
remoteclaw plugin add @remoteclaw/feishu
```

Configure the Feishu/Lark app credentials in RemoteClaw, then connect the plugin to the chats where agents should receive and send messages.
